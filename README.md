# Chretien Banza - Portfolio

Modern, minimal portfolio website built with React + TypeScript + Vite.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

Build output goes to `dist/`. Deploy to Vercel, Netlify, or any static host.
